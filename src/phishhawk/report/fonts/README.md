# Report fonts

The HTML report embeds these two fonts as `data:` URIs, so it keeps its look
without loading anything from the network.

| File | Font | Licence |
|---|---|---|
| `Outfit-Variable-latin.woff2` | [Outfit](https://github.com/Outfitio/Outfit-Fonts), variable weight, Latin subset | SIL OFL 1.1, see `Outfit-OFL.txt` |
| `JetBrainsMono-Variable-latin.woff2` | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), variable weight, Latin subset | SIL OFL 1.1, see `JetBrainsMono-OFL.txt` |

Both files come from the Fontsource packages `@fontsource-variable/outfit` and
`@fontsource-variable/jetbrains-mono` (version 5.3.0).
